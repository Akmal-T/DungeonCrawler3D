SFX Audio Files
================

SoundManager expects the following audio files:
- hit_player.wav (played when player takes damage)
- hit_enemy.wav (played when enemy takes damage)

You can add more SFX by:
1. Adding .wav/.ogg files to this folder
2. Updating SoundManager.gd to call _play_sfx() with the file path

Recommended free SFX sources:
- https://kenney.nl/assets (Impact Sounds pack)
- https://freesound.org
- https://opengameart.org
